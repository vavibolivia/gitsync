# GitSync 1.3.0 검수 계획 및 결과

| 항목 | 내용 |
|---|---|
| 대상 | GitSync.Core (엔진), GitSync.Desktop (WPF exe), GitSync.Server (API), web (프론트엔드) |
| 기준일 | 2026-11-18 |
| 환경 | Windows 11, .NET 10.0.404, Git 2.56.1, Chrome (최신), Edge headless |
| 판정 기준 | 모든 **필수(P1)** 케이스 통과, 발견 결함은 수정 후 재시험 통과 |

## 1. 시험 전략

| 단계 | 방법 | 실 서비스 대체 |
|---|---|---|
| 엔진 통합 시험 | xUnit 자동 시험 (`tests/GitSync.Tests`) | **FakeForge**: GitHub REST · GitLab REST v4 · git smart-HTTP(`git http-backend`)를 그대로 흉내 내는 시험 서버. 실제 HTTP 인증 헤더, fetch/push, 페이지네이션, 저장소 생성 경로를 모두 통과 |
| 서버 E2E | 실제 `GitSync.Server` 프로세스를 띄워 HTTP API 호출 | FakeForge |
| 웹 UI | 실제 Chrome에서 사용자 조작 | FakeForge + Server |
| 데스크톱 UI | 렌더링 스냅샷 + 실행 파일 스모크 | 데모 데이터 |
| 회귀 방지 검증 | 변이 시험 (핵심 규칙을 일부러 망가뜨려 시험이 잡는지 확인) | — |
